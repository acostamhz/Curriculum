# GerenteAI

GerenteAI is an AI-powered business copilot created for small businesses.

Its objective is to help business owners make better decisions using conversational artificial intelligence.

## Target Audience

- Grocery stores
- Restaurants
- Hardware stores
- Pharmacies
- Coffee shops
- Barber shops
- Small local businesses

## Technologies

- Next.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- Google Gemini
- AI SDK
- Docker

## AI Features

- Streaming responses
- Conversation memory
- Retrieval-Augmented Generation (RAG)
- Semantic search
- Prompt engineering
- Tool calling

## Planned Integrations

- WhatsApp Business API
- n8n
- Financial reports
- Sales analytics
- Inventory recommendations

## Current Status

The project is under active development and follows a modular architecture.
